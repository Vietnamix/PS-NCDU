# PS-NCDU

**Windows 磁盘空间分析器，基于 PowerShell，提供本地网页界面和实时可导航的目录树。**

[![Version](https://img.shields.io/badge/version-6.28-2c6cb0)](https://github.com/Vietnamix/PS-NCDU)
[![PowerShell](https://img.shields.io/badge/PowerShell-5.1%2B-5391FE?logo=powershell&logoColor=white)](https://github.com/Vietnamix/PS-NCDU)
[![Platform](https://img.shields.io/badge/platform-Windows-0078D6?logo=windows&logoColor=white)](https://github.com/Vietnamix/PS-NCDU)
[![License](https://img.shields.io/badge/license-MIT-3fa45b)](License.md)

PS-NCDU 是一个**单文件、完全独立**的 PowerShell 脚本，几秒钟内就能回答"是什么占满了这块磁盘？"。无需任何参数即可运行：它启动一个小型本地网页服务器，打开浏览器，让你选择要分析的文件夹或磁盘。目录树在扫描过程中**实时**构建，大小逐个文件夹填充，扫描结束前你就可以自由浏览。灵感来自 Unix 工具 [`ncdu`](https://dev.yorhel.nl/ncdu)，专为 Windows 生态设计，无任何外部依赖。

## 概述

与生成静态 HTML 报告供事后打开的 3.x 版本不同，PS-NCDU 现在是一个**本地网页应用**。脚本在 `127.0.0.1` 上启动 HTTP 服务器（端口 8787，若被占用则自动回退到空闲端口），受会话令牌保护，并在默认浏览器中打开界面。所有设置都在该界面中完成：要分析的文件夹、深度、显示过滤、排除项、语言。

服务器仅运行在本机，不暴露在网络上，可通过控制台的 `Ctrl+C` 或界面中的"退出服务器"按钮停止。

## 功能

### 扫描与导航
- **实时目录树**：枚举时结构即刻显现，大小随计算逐个文件夹到达。
- **扫描期间自由导航**：点击文件夹进入，用面包屑返回上级，无需等待结束。
- **可调或无限深度**：预加载几层以保持流畅显示，或加载完整目录树。无论深度如何，大小始终精确；未预加载的层级一键加载。
- **交错式无限扫描**：无限深度下，每个子树在测量前才被枚举，因此大小在最初几秒就开始显示，而无需等待遍历整个磁盘。
- **中止**："中止"按钮停止当前扫描并交还控制权；启动新扫描会自动取消旧扫描。
- **可点击的灰色文件夹**：已排除、连接点、受保护（ACL）或未预加载的文件夹保持可见并可按需扫描，若已有扫描在运行则排队等待。
- **处理顺序与显示对齐**：进度自上而下填充，不会跳跃。

### 结果查看
- **名称 / 大小排序**：默认按大小（最大在顶部），扫描期间平滑处理以避免行跳动；一键切换为按名称排序。
- **比例条**和相对于当前文件夹的百分比。
- 每个文件夹的子文件夹与文件**递归计数**。
- **按需列出文件**：打开文件夹时显示，按大小排序，最多 1000 个最大文件。
- **文件类型图标**：约 120 种常见扩展名（图片、视频、音频、PDF、办公文档、压缩包、代码、可执行文件、字体、磁盘映像、数据库、电子书、证书、快捷方式），一眼识别类型。
- **显示过滤**：隐藏小于 1 MB、100 MB 或 1 GB 的项目以提高可读性，不改变扫描本身。
- **彩色状态点**：已扫描、计划中、排队中、进行中、灰色；内置图例和帮助解释每种状态。
- **浅色 / 深色主题**。

### 分析窗口
- **内置文件夹浏览器**：驱动器、点击导航、上级文件夹、"选择此文件夹"。不依赖 Windows 原生选择器，即使远程访问也可靠。
- **快速访问**用户配置文件，**最近记录**支持单条移除与清空，**驱动器**带占用率条。
- **路径验证**：输入时实时验证，启动时再次验证。
- **排除项**：始终跳过的系统文件夹列表，外加一个可为本次扫描额外排除路径的输入框。
- **设置记忆**（路径、深度、过滤、排序、语言）跨会话保存。
- **回车**启动，已有扫描显示时按 **Esc** 或关闭按钮收起窗口。

### 语言
- **42 种语言**，覆盖全球 80% 以上人口：英语、中文、印地语、西班牙语、法语、阿拉伯语、孟加拉语、葡萄牙语、俄语、乌尔都语、印尼语、德语、日语、韩语、意大利语、土耳其语、越南语、波兰语、荷兰语、乌克兰语、罗马尼亚语、捷克语、希腊语、瑞典语、匈牙利语、波斯语、泰语、马来语、菲律宾语、斯瓦希里语、泰米尔语、泰卢固语、马拉地语、古吉拉特语、卡纳达语、马拉雅拉姆语、旁遮普语、希伯来语、豪萨语、缅甸语、阿姆哈拉语、高棉语。
- 自动检测系统语言，分析窗口中有选择器，选择会被记住。
- 阿拉伯语、乌尔都语、波斯语和希伯来语支持从右到左书写。
- 最近新增的 30 种语言翻译为尽力而为；欢迎母语者审阅，尤其是阿姆哈拉语、高棉语、缅甸语、豪萨语和印度诸语言。

## 安装

克隆仓库或直接下载 `ps-ncdu.ps1` 文件：

```powershell
git clone https://github.com/Vietnamix/PS-NCDU.git
cd PS-NCDU
```

脚本以**带 BOM 的 UTF-8** 编码。请勿以其他编码重新保存：否则 PowerShell 5.1 会按 ANSI 读取文件，导致界面中的重音字符和非拉丁语言损坏。

> **执行策略**：如果 Windows 阻止脚本运行，可为当前会话放行：
>
> ```powershell
> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
> ```
>
> 此命令不会做任何永久更改：仅对当前打开的 PowerShell 窗口生效。

## 使用

**没有任何命令行参数**。直接运行脚本即可：

```powershell
.\ps-ncdu.ps1
```

脚本将：

1. 启动本地服务器并在控制台显示其地址（例如 `http://127.0.0.1:8787/?token=...`）；
2. 在默认浏览器中打开该地址；
3. 显示分析窗口，在其中选择文件夹、深度和显示方式，然后点击"分析"。

如果浏览器未自动打开，请复制控制台中显示的地址。停止方式：控制台按 `Ctrl+C`，或点击界面中的"退出服务器"按钮。

要扫描系统路径（`C:\Windows`、磁盘根目录），请**以管理员身份**运行控制台，否则受保护的文件夹将显示为灰色。

## 界面说明

- **顶部栏**：面包屑、当前文件夹总计与计数、进度百分比、名称 / 大小排序按钮、主题、扫描期间的"中止"按钮、"新扫描"。
- **目录树**：每个文件夹或文件一行，包含状态点、类型图标、名称、比例条、百分比、计数和大小。灰色文件夹一键扫描；"扫描灰色文件夹 (N)"按钮可处理当前文件夹中的全部灰色项。
- **底部栏**：当前阶段、此刻正在读取的路径、扫描深度、计时器，以及图例 / 帮助面板。
- **分析窗口**（"新扫描"）：两栏布局。左侧为目标（路径、内置浏览器、快速访问、最近记录、驱动器）。右侧为选项（带滑块和无限模式的深度、显示过滤、排除项）。语言选择器位于该窗口的标题栏。

## 扫描原理

引擎分阶段工作。**枚举**阶段发现目录结构并实时推送到目录树；**大小计算**阶段随后按显示顺序遍历每个一级子树，每秒一次将部分大小向上汇总到所有祖先节点。事件通过 SSE 流从服务器推送到页面。

几个值得了解的设计选择：

- **一次只运行一个扫描**，这是有意为之：两个并行磁盘扫描会相互拖慢。额外请求（灰色文件夹）会排队并在结束时处理。
- **单线程服务器**：中止是协作式的。关闭连接（"中止"按钮或新扫描）会使服务器的下一次写入失败，从而设置一个在循环中检查的标志；实际停止最多需要一秒。
- **跳过连接点和重解析点**以避免循环和重复计数。
- **网络驱动器**：启动时不查询其空间，避免映射驱动器不可达（例如 VPN 断开）时挂起。
- **.NET 流式枚举**（`EnumerateFiles` / `EnumerateDirectories`）而非 `Get-ChildItem`，在 PowerShell 5.1 中明显更快。性能上限仍是解释型脚本的水平：直接读取 NTFS MFT 的原生工具要快得多，这一点是可以接受的。

## 工作文件

| 位置                                 | 作用                                    |
| ------------------------------------ | --------------------------------------- |
| `%TEMP%\psncdu\psncdu_debug.log`     | 服务器和扫描的详细日志                  |
| `%TEMP%\psncdu\history.txt`          | 已扫描路径的历史记录（"最近记录"）      |

始终排除在扫描之外的系统文件夹：`C:\Windows\WinSxS`、`C:\Windows\Installer`、`C:\$Recycle.Bin`、`C:\System Volume Information`、`C:\Recovery`、`C:\ProgramData\Microsoft\Windows Defender`、`C:\Windows\SoftwareDistribution`。你可以在分析窗口的"排除项"部分为本次扫描添加更多。

## 故障排除

| 现象                                                     | 可能原因 / 解决方法                                                                                                                              |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 脚本无法启动                                             | 执行策略，参见[安装](#安装)中的说明。                                                                                                            |
| "网页服务器需要 FullLanguage 模式"                       | 会话处于 ConstrainedLanguage（AppLocker / WDAC 策略）。请从不受限的控制台运行，或使用可在受限模式下工作的 3.2 版本（静态 HTML 报告）。          |
| 界面中重音字符或非拉丁语言损坏                           | `.ps1` 被重新保存时丢失了 UTF-8 BOM。请恢复原始编码。                                                                                            |
| 大量灰色"受保护"文件夹                                   | 权限不足。请**以管理员身份**重新启动 PowerShell。                                                                                                |
| 浏览器未打开                                             | 手动打开控制台中显示的地址（含令牌）。                                                                                                           |
| 启动时页面空白或服务器卡住                               | 检查日志 `%TEMP%\psncdu\psncdu_debug.log`。不可达的网络驱动器可能导致旧版本挂起；自 5.14 起已修复。                                              |
| 对磁盘进行无限扫描时没有任何反应                         | 自 6.17 起已修复（交错式枚举）。如仍然存在，请检查顶部栏显示的版本。                                                                             |
