# PS-NCDU

**Анализатор дискового пространства для Windows на PowerShell с локальным веб-интерфейсом и деревом, по которому можно перемещаться в реальном времени.**

[![Version](https://img.shields.io/badge/version-6.28-2c6cb0)](https://github.com/Vietnamix/PS-NCDU)
[![PowerShell](https://img.shields.io/badge/PowerShell-5.1%2B-5391FE?logo=powershell&logoColor=white)](https://github.com/Vietnamix/PS-NCDU)
[![Платформа](https://img.shields.io/badge/platform-Windows-0078D6?logo=windows&logoColor=white)](https://github.com/Vietnamix/PS-NCDU)
[![Лицензия](https://img.shields.io/badge/license-MIT-3fa45b)](License.md)

PS-NCDU: это **однофайловый автономный** скрипт PowerShell, который за секунды отвечает на вопрос «что занимает место на этом диске?». Запущенный без параметров, он поднимает небольшой локальный веб-сервер, открывает браузер и предлагает выбрать папку или диск для анализа. Дерево строится **в реальном времени** во время сканирования, размеры заполняются папка за папкой, и по нему можно свободно перемещаться ещё до завершения. Вдохновлён Unix-утилитой [`ncdu`](https://dev.yorhel.nl/ncdu), создан для экосистемы Windows, без внешних зависимостей.

![Интерфейс PS-NCDU](PS-NCDU_interface_v6.27b.png)

*PowerShell 5.1+ · Windows · Без установки · Один файл · 42 языка*

## Обзор

В отличие от версий 3.x, которые создавали статический HTML-отчёт для последующего открытия, PS-NCDU теперь является **локальным веб-приложением**. Скрипт запускает HTTP-сервер на `127.0.0.1` (порт 8787, при занятости автоматически подбирается свободный), защищённый сессионным токеном, и открывает интерфейс в браузере по умолчанию. Всё настраивается в этом интерфейсе: папка для анализа, глубина, фильтр отображения, исключения, язык.

Сервер работает только на локальной машине, не доступен из сети и останавливается по `Ctrl+C` в консоли или кнопкой «Остановить сервер» в интерфейсе.

## Возможности

### Сканирование и навигация
- **Дерево в реальном времени**: структура появляется во время перечисления, размеры приходят папка за папкой по мере вычисления.
- **Свободная навигация во время сканирования**: щёлкните папку, чтобы войти, и хлебные крошки, чтобы подняться, не дожидаясь окончания.
- **Настраиваемая или неограниченная глубина**: предзагрузите несколько уровней для плавного отображения или всё дерево целиком. Размеры всегда точны при любой глубине; непредзагруженные уровни подгружаются одним щелчком.
- **Чередующееся неограниченное сканирование**: при неограниченной глубине каждое поддерево перечисляется непосредственно перед измерением, поэтому размеры появляются уже в первые секунды, а не после обхода всего диска.
- **Прерывание**: кнопка «Остановить» прекращает текущее сканирование и возвращает управление; запуск нового сканирования автоматически отменяет предыдущее.
- **Кликабельные серые папки**: исключённые, соединения, защищённые (ACL) или непредзагруженные папки остаются видимыми и сканируются по требованию, с очередью, если сканирование уже идёт.
- **Порядок обработки совпадает с отображением**: прогресс заполняется сверху вниз, без скачков.

### Чтение результатов
- **Сортировка Имя / Размер**: по умолчанию по размеру (самые большие сверху), со сглаживанием во время сканирования, чтобы строки не прыгали; один щелчок переключает на сортировку по имени.
- **Полосы долей** и проценты относительно текущей папки.
- **Рекурсивные счётчики** подпапок и файлов по каждой папке.
- **Файлы по требованию** при открытии папки, отсортированные по размеру, не более 1000 самых больших.
- **Значки по типу файла**: около 120 распространённых расширений (изображения, видео, аудио, PDF, офисные документы, архивы, код, исполняемые файлы, шрифты, образы дисков, базы данных, электронные книги, сертификаты, ярлыки), чтобы распознавать типы с первого взгляда.
- **Фильтр отображения**: скрывать элементы меньше 1 МБ, 100 МБ или 1 ГБ для удобства чтения, не меняя сканирование.
- **Цветные точки состояния**: отсканировано, запланировано, в очереди, в процессе, серое; встроенные легенда и справка объясняют каждое состояние.
- **Светлая / тёмная тема**.

### Окно анализа
- **Встроенный обозреватель папок**: диски, навигация щелчком, родительская папка, «Выбрать эту папку». Не зависит от системного диалога Windows, поэтому надёжно работает даже при удалённом доступе.
- **Быстрый доступ** к профилям пользователей, **недавние** с удалением по одному и полной очисткой, **диски** с полосой заполнения.
- **Проверка пути** на лету и при запуске.
- **Исключения**: список системных папок, которые всегда пропускаются, плюс поле, чтобы исключить дополнительные на время сканирования.
- **Запоминаемые настройки** (путь, глубина, фильтр, сортировка, язык) между сеансами.
- **Enter** для запуска, **Esc** или кнопка закрытия, чтобы скрыть окно, когда сканирование уже отображается.

### Языки
- **42 языка**, охватывающие более 80 % населения мира: английский, китайский, хинди, испанский, французский, арабский, бенгальский, португальский, русский, урду, индонезийский, немецкий, японский, корейский, итальянский, турецкий, вьетнамский, польский, нидерландский, украинский, румынский, чешский, греческий, шведский, венгерский, персидский, тайский, малайский, филиппинский, суахили, тамильский, телугу, маратхи, гуджарати, каннада, малаялам, панджаби, иврит, хауса, бирманский, амхарский, кхмерский.
- Автоматическое определение языка системы, переключатель в окне анализа, выбор запоминается.
- Письмо справа налево для арабского, урду, персидского и иврита.
- Переводы 30 последних языков сделаны по мере возможностей; вычитка носителями приветствуется, особенно для амхарского, кхмерского, бирманского, хауса и индийских языков.

## Установка

Клонируйте репозиторий или просто скачайте файл `ps-ncdu.ps1`:

```powershell
git clone https://github.com/Vietnamix/PS-NCDU.git
cd PS-NCDU
```

Скрипт сохранён в кодировке **UTF-8 с BOM**. Не пересохраняйте его в другой кодировке: PowerShell 5.1 прочитает файл как ANSI и испортит диакритику и нелатинские языки интерфейса.

> **Политика выполнения**: если Windows блокирует запуск скриптов, разрешите его для текущего сеанса:
>
> ```powershell
> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
> ```
>
> Эта команда ничего не меняет навсегда: она действует только в открытом окне PowerShell.

## Использование

**Параметров командной строки нет**. Просто запустите скрипт:

```powershell
.\ps-ncdu.ps1
```

Скрипт:

1. запускает локальный сервер и выводит его адрес в консоль (например `http://127.0.0.1:8787/?token=...`);
2. открывает этот адрес в браузере по умолчанию;
3. показывает окно анализа, где вы выбираете папку, глубину и отображение, затем нажимаете «Анализировать».

Если браузер не открылся сам, скопируйте адрес из консоли. Чтобы остановить: `Ctrl+C` в консоли или кнопка «Остановить сервер» в интерфейсе.

Для сканирования системных путей (`C:\Windows`, корень диска) запускайте консоль **от имени администратора**: иначе защищённые папки будут показаны серым.

## Интерфейс

- **Шапка**: хлебные крошки, итог по текущей папке со счётчиками, процент выполнения, кнопка сортировки Имя / Размер, тема, «Остановить» во время сканирования, «Новое сканирование».
- **Дерево**: по строке на папку или файл, с точкой состояния, значком типа, именем, полосой доли, процентом, счётчиками и размером. Серые папки сканируются одним щелчком; кнопка «Сканировать серые папки (N)» обрабатывает все такие папки в текущей.
- **Подвал**: текущий этап, путь, который читается прямо сейчас, глубина сканирования, таймер и панель Легенда / Справка.
- **Окно анализа** («Новое сканирование»): в две колонки. Слева назначение (путь, встроенный обозреватель, быстрый доступ, недавние, диски). Справа параметры (глубина с ползунком и неограниченным режимом, фильтр отображения, исключения). Переключатель языка находится в шапке этого окна.

## Как работает сканирование

Движок работает поэтапно. **Перечисление** обнаруживает структуру и по ходу передаёт её в дерево; затем **вычисление размеров** обходит каждое поддерево первого уровня в порядке отображения, раз в секунду поднимая частичные размеры ко всем предкам. События идут от сервера к странице через SSE.

Несколько проектных решений, о которых стоит знать:

- **Одно сканирование за раз**, намеренно: два параллельных сканирования диска замедляли бы друг друга. Дополнительные запросы (серые папки) ставятся в очередь и обрабатываются в конце.
- **Однопоточный сервер**: прерывание кооперативное. Закрытие соединения (кнопка «Остановить» или новое сканирование) приводит к сбою следующей записи сервера, что поднимает флаг, проверяемый в циклах; фактическая остановка занимает до секунды.
- **Соединения и точки повторной обработки** пропускаются, чтобы избежать циклов и двойного учёта.
- **Сетевые диски**: их объём не запрашивается при запуске, что исключает зависание, когда подключённый диск недоступен (например, отключён VPN).
- **Потоковое перечисление .NET** (`EnumerateFiles` / `EnumerateDirectories`) вместо `Get-ChildItem`, заметно быстрее в PowerShell 5.1. Потолок производительности остаётся потолком интерпретируемого скрипта: нативные утилиты, читающие MFT NTFS напрямую, намного быстрее, и это принимается как данность.

## Рабочие файлы

| Расположение                         | Назначение                                     |
| ------------------------------------ | ---------------------------------------------- |
| `%TEMP%\psncdu\psncdu_debug.log`     | Подробный журнал сервера и сканирований        |
| `%TEMP%\psncdu\history.txt`          | История сканированных путей («Недавние»)       |

Системные папки, всегда исключаемые из сканирования: `C:\Windows\WinSxS`, `C:\Windows\Installer`, `C:\$Recycle.Bin`, `C:\System Volume Information`, `C:\Recovery`, `C:\ProgramData\Microsoft\Windows Defender`, `C:\Windows\SoftwareDistribution`. Другие можно добавить на время сканирования в разделе «Исключения» окна анализа.

## Устранение неполадок

| Симптом                                                       | Вероятная причина / решение                                                                                                                    |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Скрипт не запускается                                         | Политика выполнения, см. примечание в разделе [Установка](#установка).                                                                         |
| «Веб-сервер требует режим FullLanguage»                       | Сеанс работает в ConstrainedLanguage (политика AppLocker / WDAC). Запустите из неограниченной консоли или используйте версию 3.2 (статический HTML-отчёт), работающую в ограниченном режиме. |
| Диакритика или нелатинские языки в интерфейсе искажены        | Файл `.ps1` был пересохранён без UTF-8 BOM. Восстановите исходную кодировку.                                                                    |
| Много серых папок «защищено»                                  | Недостаточно прав. Перезапустите PowerShell **от имени администратора**.                                                                        |
| Браузер не открывается                                        | Откройте адрес из консоли вручную (вместе с токеном).                                                                                          |
| Пустая страница или зависший сервер при запуске               | Проверьте журнал `%TEMP%\psncdu\psncdu_debug.log`. Недоступный сетевой диск мог подвешивать старые версии; исправлено с 5.14.                   |
| Ничего не происходит при неограниченном сканировании диска    | Исправлено с 6.17 (чередующееся перечисление). Если повторяется, проверьте версию в шапке.                                                     |

## Участие

Вклад приветствуется:

1. Сделайте *fork* репозитория.
2. Создайте ветку (`git checkout -b feature/my-feature`).
3. Сохраняйте кодировку **UTF-8 с BOM** и *here-strings* PowerShell нетронутыми.
4. Для переводов: каждый язык является объектом в словаре `I18N` внутри скрипта; сравните его ключи с ключами `en`, чтобы найти недостающие.
5. Откройте *pull request* с понятным описанием изменений.

Для ошибок и идей откройте **issue**, указав версию Windows, версию PowerShell, версию PS-NCDU из шапки и по возможности фрагмент журнала `%TEMP%\psncdu\psncdu_debug.log`.
